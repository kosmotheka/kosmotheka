Inline message inside a screen. Every problem message follows the app's pattern: what happened, why it usually happens, what to do, and a button for the most likely fix (`AlertAction`). Compose `Alert` > Lucide icon + `AlertTitle` + `AlertDescription` (+ `AlertAction`). Variants: `default` (information) and `destructive` (the action did not happen). See the error catalog in the guidelines.
