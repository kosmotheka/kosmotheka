Confirmation before anything destructive or irreversible ("Delete this book?", "Forget this device?"). Compose `AlertDialog` > `AlertDialogTrigger` + `AlertDialogContent` > `AlertDialogHeader` (`AlertDialogTitle`, `AlertDialogDescription`) + `AlertDialogFooter` (`AlertDialogCancel`, `AlertDialogAction`). Say what will happen in plain words; the action button names the action ("Delete"), never "OK".
