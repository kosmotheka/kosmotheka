category: Actions
---

Buttons for every action in the app. Variants: `default` (the one primary action on a screen, e.g. "Add book", "Save"), `outline` (secondary actions), `secondary`, `ghost` (toolbar and icon actions), `destructive` (delete, forget device; always behind a confirmation), `link`. Sizes: `xs`, `sm`, `default`, `lg`, and square `icon`, `icon-xs`, `icon-sm`, `icon-lg` for icon-only buttons, which must carry an `aria-label`. Put a Lucide icon as the first child for a leading icon. Touch targets on mobile must reach 44 px: prefer `lg` or add padding around small buttons.
