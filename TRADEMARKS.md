# Trademark policy

The code of Kosmotheka is free software. Its **name and logo are not**: the AGPL and the MIT licence cover the code and the specification, not the "Kosmotheka" name or the logo. This page says what that means in practice.

## You can

- Talk about the project, write about it and link to it.
- Use the name and the logo to refer to the project, for example in an article or a review.
- Say that your server "works with Kosmotheka".
- Run the code and change it for yourself, as the licence allows.

## You cannot

- Publish an app, a server or a service, modified or not, **under the Kosmotheka name or with the logo** in a way that makes people think it is the official one.
- Use the name or the logo in a way that suggests the project endorses you.

If you publish a fork, give it its own name and its own icon.

## What is official

- The official app is the one on Google Play and the downloads on [kosmotheka.com](https://kosmotheka.com).
- The official server is kosmotheka.app.

Hosting your own server is fine, and the official app can connect to it. It simply is not "the official Kosmotheka".

## Questions

Write to [info@kosmotheka.com](mailto:info@kosmotheka.com) if you are not sure whether a use is allowed.
