The code of Kosmotheka is free. **The name and the logos are not**: the licences of the code (AGPL) and of the specification (MIT) do not cover them. The full policy is in [TRADEMARKS.md](https://github.com/kosmotheka/kosmotheka/blob/main/TRADEMARKS.md); this is the gist.

## What you can do

- Talk about the project, write about it and link to it.
- Use the name and the logos **to refer to the project**: in an article, a review or a list of apps.
- Say that your server "works with Kosmotheka".
- Use the code and change it, as the licence allows.

## What you cannot

- Publish an app, a server or a service, changed or not, **with the name or the logos** in a way that makes it look official.
- Use them in a way that suggests the project endorses you.
- Change the logos (colours, shape, proportions) or put them inside a logo of your own.

If you make your own version, give it its own name and icon.

**What is official** is the app on Google Play, the downloads on [kosmotheka.com](https://kosmotheka.com) and the server `api.kosmotheka.app`. Running your own server is fine, and the official app connects to it; it simply is not "the official Kosmotheka", and the app tells whoever uses it.

If you are not sure whether a use is allowed, write to [info@kosmotheka.com](mailto:info@kosmotheka.com).

## The logos to download

They are all SVG: sharp at any size. Use the one that contrasts best with your background and **leave room around it**: at least the height of the symbol's star. Do not stretch them or change their colours.
