title: Contribute
description: How to help with Kosmotheka and how it is built.
---

The usual procedure applies: open an issue first if the change is big, fork and make a branch, pass the checks and open a pull request. Anyone who wants to understand how it works inside will find the architecture explained here, the sync engine and the audit method.

This part is still being translated and put in order. You can already read:

- [CONTRIBUTING.md](https://github.com/kosmotheka/kosmotheka/blob/main/CONTRIBUTING.md), the procedure and the rules that matter.
- [SECURITY.md](https://github.com/kosmotheka/kosmotheka/blob/main/SECURITY.md), how to report a vulnerability privately.
- [The decision log](https://github.com/kosmotheka/kosmotheka/blob/main/docs/DECISIONS.md) and [the architecture](https://github.com/kosmotheka/kosmotheka/blob/main/docs/architecture), in Spanish.
- [CODE_OF_CONDUCT.md](https://github.com/kosmotheka/kosmotheka/blob/main/CODE_OF_CONDUCT.md).
